\begin{abstract}
Creating a reusable tool is an investment: an agent pays a fixed cost now in
exchange for uncertain future reuse. We introduce a paired benchmark that tests
whether language-model agents preserve online allocation behavior when the same
investment decision moves from an abstract keep/pass frame to reusable code
construction. Claude Haiku reserves budget in the abstract frame but makes
100\% of its script builds on first sight, compared with 28\% abstract
first-sight commitment. A preregistered framing ladder localizes this shift to
required code emission: a declarative solver claim yields 39\% first-sight
commitment, while requiring code---without correctness-dependent reward or a
hand-solving option---raises it to 100\%. Across build charges spanning eager,
selective, and never-build regimes, Haiku's abstract choices adjust to the
economics, whereas its code-required choices remain at 98--100\% first sight,
including when never building is optimal. The shift also appears in Claude
Opus and, after a preregistered competence gate, in GPT-5.4-mini (16.7\%
abstract versus 87.9\% code-required). In contrast, competence-qualified
GPT-5.6 Sol preserves reserve across the same comparison (19.4\% versus
27.8\%; the paired interval includes zero), demonstrating that the tested
capability is achievable rather than structurally precluded by code generation.
In a separate proof-of-possibility case study, a Qwen-14B policy trained from
reward acquires abstract reserve and generalizes it across held-out lexical
reskins, but remains eager in reusable script creation.
Together, these results establish online tool investment as a discriminative
capability boundary: constructive framing can suppress an available allocation
policy, but a capable model can preserve it.
\end{abstract}

\section{Introduction}

Language-model agents increasingly create scripts, wrappers, macros, and skills
that can be reused across tasks. Existing evaluations ask whether a model can
write a correct tool, choose an available tool, or benefit from a growing
library \cite{cai2024latm,qian2023creator,huang2024ultratool,qu2025toollearningsurvey}.
They largely leave a prior decision unmeasured: \emph{when should the agent
build?}

Building is worthwhile only when its fixed cost can be amortized over future
reuse. An agent facing an unfamiliar problem type therefore has three
possibilities: build immediately, wait for evidence of recurrence, or never
build. Building every initially plausible tool wastes a scarce construction
budget on one-offs; waiting too long forfeits useful reuse. This is an online
rent-or-buy problem, related to ski rental \cite{karlin1994competitive}, but
with multiple latent problem classes, a shared build budget, and a constructive
action generated by a language model.

Eager building is ambiguous when observed in an ordinary tool benchmark. The
agent may lack an allocation policy, may possess it but fail to activate it in
the tool context, or may understand the economics while being pulled toward
the current problem. We separate these explanations by presenting identical
problem streams and information in paired decision frames. The abstract frame
asks the model to keep or pass colored items. The constructive frame asks it
to claim or write a reusable solver for the corresponding numeric problem
class. This design first establishes whether an allocation policy is present,
then tests whether it survives constructive reframing.

Our results support five conclusions. First, with the number of latent classes
disclosed in both frames, Haiku commits on first sight in 28\% of abstract
decisions but 100\% of reusable-script decisions. Second, a preregistered
framing ladder and a construction-only control isolate required code emission
as sufficient to reproduce the full shift within this benchmark. Third, the
affected code-required policy is economically inelastic: it remains almost
fully eager as visible build charges move from zero to a level at which every
build is net-negative. Fourth, a Qwen-14B policy can acquire reserve from reward
and preserve it when balls and urns are replaced by unseen abstract vocabularies,
yet remains as eager as its base model during script construction. Fifth, the
benchmark is difficult but passable. Opus and
GPT-5.4-mini exhibit the framing shift, whereas GPT-5.6 Sol preserves reserve
after code becomes required.

The paper contributes:
\begin{enumerate}
    \item an online tool-investment formulation and benchmark with uncertain
    recurrence, scarce irreversible builds, paired streams, and explicit
    timing outcomes;
    \item a same-information test that separates absent allocation competence
    from framing-dependent non-expression;
    \item a causal study combining a preregistered framing ladder, a
    code-required control, and an economic response surface;
    \item a proof-of-possibility reward-learning case study distinguishing
    policy acquisition from cross-context activation; and
    \item a preregistered, competence-gated model panel that contains both a
    large cross-frame shift and successful cross-frame preservation.
\end{enumerate}

\section{Related Work}

\paragraph{Tool creation and skill libraries.}
LATM amortizes an expensive model's tool creation over many uses
\cite{cai2024latm}; CREATOR separates tool creation, decision, execution, and
rectification \cite{qian2023creator}; and ReGAL, LILO, and TroVE induce reusable
program abstractions or libraries \cite{stengeleskin2024regal,grand2024lilo,wang2024trove}.
These systems generally assume that a recurring task warrants construction or
induce libraries from a pre-existing corpus. Work on library-learning failures
shows that nominally reusable abstractions may see little actual reuse
\cite{berlotattwell2024librarylearning}. Library Drift studies the downstream
cost of unbounded accumulation and repairs it through retirement and bounded
library management \cite{zhang2026librarydrift}. Our object precedes these:
whether to author an irreversible artifact before recurrence is known.

\paragraph{Tool-use evaluation.}
UltraTool and broader surveys evaluate planning, tool creation, selection, and
execution \cite{huang2024ultratool,qu2025toollearningsurvey}. These are primarily
capability or accuracy evaluations. Our outcome is a disposition conditional
on demonstrated competence: whether an agent preserves budget until reuse
evidence justifies construction.

\paragraph{Sequential decision-making and early commitment.}
Prior work evaluates regret of LLMs selecting from fixed actions in online
learning and games \cite{park2025regret}. Meta-bandit training can produce
effective but increasingly exploitative policies that abandon exploration too
early \cite{chen2025greedy}. Mehta \cite{mehta2026commit} studies
representational commitment within a single agent trajectory. Our commitment
is instead an externally visible, irreversible construction decision whose
cost is amortized over a stream. We borrow the rent-or-buy perspective from
online algorithms \cite{karlin1994competitive}, but do not claim that our
multi-class, budgeted benchmark is identical to textbook ski rental.

\section{Online Tool Investment}

\subsection{Decision process}

An episode contains a horizon of $T$ items with latent classes
$c_t \in \{1,\ldots,N\}$. At time $t$, the agent observes the current item and
history $h_t$, has remaining build budget $b_t$, and chooses whether to commit
to class $c_t$. A commitment is irreversible and consumes one of $B$ available
builds. Once a class has been built, later occurrences can reuse its artifact.
The class frequencies are unknown at the start of the episode.

For the economic experiments, a solved or collected occurrence contributes
one point and a commitment costs $K$. For policy $\pi$,
\begin{equation}
U(\pi) =
\sum_{t=1}^{T} r_t(\pi)
- K\sum_{c=1}^{N}\mathbb{I}\{\pi\text{ commits to }c\},
\end{equation}
subject to at most $B$ commitments. The best action depends on both recurrence
evidence and remaining budget. A one-off class should not consume a build;
a sufficiently frequent class should.

\subsection{Benchmark construction}

We instantiate the process with streams of $T=60$ numeric problems drawn from
eight latent problem families. Each canonical stream contains approximately
three ``hot'' classes that recur 13--23 times and several ``trap'' classes that
appear only 1--6 times. An early-trap constraint places a rare class among the
first $B$ opportunities, making first-sight commitment costly. The hardened
numeric pool is designed to make unaided hand solving approximately unavailable
while retaining script-based solvability.

The abstract and constructive environments are views of the same latent class
sequence. In the abstract urn frame, the model observes a colored item and
chooses \textsc{keep} or \textsc{pass}. Keeping a class commits budget and
collects its occurrences. In the reusable-script frame, the model encounters a
numeric problem and may write a class-level solver that can be run on later
instances. We pair byte-identical class streams across conditions.

The main causal condition, A2, tells both the model and the reference that
exactly $N=8$ classes occur. A separate no-$N$ condition is ecologically
natural but gives the Bayesian reference more information than the model.
Unless stated otherwise, causal comparisons use A2.

\subsection{Outcomes and references}

Our primary outcomes are behavioral timing measures:
\begin{itemize}
    \item \textbf{First-sight commitment}: the proportion of realized
    commitments made on a class's first occurrence.
    \item \textbf{First-sight hazard}: commitments on eligible first-occurrence
    turns divided by eligible first-occurrence turns.
    \item \textbf{Lateness}: the occurrence index at commitment minus the
    class's first occurrence; zero denotes immediate commitment.
\end{itemize}

For the original urn experiment, we use an exact finite-horizon Bayesian policy
with a symmetric Dirichlet prior as a labeled behavioral comparator. It is
Bayes-optimal for that prior, not for the engineered generator. For economic
regret we instead use an exact hindsight net optimum. On a realized stream, a
class of size $s_c$ built at first sight contributes $s_c-K$; the hindsight
reference chooses up to $B$ classes with the largest positive values. This
reference is prior-free and provides an offline upper bound, not an online
policy available to the model.

\section{Experimental Protocol}

The primary controlled subject is Claude Haiku 4.5. Claude Opus 4.8 provides a
frontier-model paired test. Qwen2.5-Coder-14B is used for reward learning.
GPT-5.4-mini and GPT-5.6 Sol are evaluated under a preregistered competence gate
with matched R0 and R2c conditions and \texttt{reasoning\_effort=none}.

Core Haiku comparisons use 12 canonical streams (seeds 2000--2011).
Repeated conditions on these streams are not independent samples: the effective
stream sample is 12, not the number of sessions. The final Qwen transfer test
uses 24 paired held-out streams (2000--2023), disjoint from training seeds.
We report numerators and denominators, paired seed differences, and
seed-clustered bootstrap intervals where applicable.

Mechanical validity is checked independently of behavioral outcomes. The
harness asserts stream hashes, separates transport failures from model
decisions, records malformed and unknown tool calls, and checks token-cap
truncation. Only mechanical failures permit reruns. Prompt, tool-choice, and
token-cap repairs discovered during benchmark development are documented in
the artifact record.

\subsection{Qualitative behavior}

Abstract decisions commonly refer prospectively to recurrence and preserving
budget. Tool-frame rationales instead center on the current problem: the model
writes a script to solve the instance in front of it, notices budget only after
spending it, and reuses scripts reactively if a class later returns. These
transcripts are consistent with the timing result but are not themselves the
causal evidence.

\section{What Triggers Eager Construction?}

\subsection{Preregistered framing ladder}

We vary the decision representation in four paired rungs:
\begin{description}
    \item[R0:] abstract free-text \textsc{keep}/\textsc{pass};
    \item[R1:] the same abstract decision through tool calls;
    \item[R2:] real numeric content with a declarative solver claim, but no code;
    \item[R3:] full reusable-script construction.
\end{description}
The preregistered localization criterion was the earliest adjacent increase of
at least 30 percentage points in first-sight commitment. The ladder is coarse,
not a complete factorial design.

\subsection{Construction-only control}

R2c retains R2's binary claim/skip loop, budget, streams, payoff, and lack of a
hand-solving option. Its only addition is a required non-empty
\texttt{solve(inputs)} implementation. Payoff is deliberately independent of
code correctness, so correctness incentives cannot explain a timing shift.
R2c reaches 100\% first-sight commitment and zero lateness, exactly matching
R3 (Table~\ref{tab:ladder}). Within this benchmark, required code emission is
therefore sufficient to reproduce the observed effect; tool-call modality,
correctness stakes, and a hand-solving escape valve are not necessary.

Code quality provides a secondary diagnostic. Only 6 of 392 tested R2c
instances (2\%) are correct, and 31 of 36 claimed solvers are degenerate across
their class. Inspection shows structurally plausible code that hard-codes
incidental parameters from the current instance instead of using the input
fields. This suggests current-instance fixation, but correctness is post hoc
and does not enter the causal R2/R2c comparison.

\section{Acquisition Without Constructive Activation}

Baseline Qwen2.5-Coder-14B is eager in both frames, so its behavior does not
identify suppression of an existing policy. We ask whether reward can install
reserve in the abstract frame and whether the learned policy activates during
script creation.

\subsection{Training}

We train from the untouched instruct model using QLoRA
\cite{dettmers2023qlora} and per-decision PPO \cite{schulman2017ppo}. Training
runs for 20 outer steps with 25 seeds per step and four rollouts per seed,
without demonstrations. The critic receives true class-rate features that are
unavailable to the actor, following the general asymmetric actor--critic idea
\cite{pinto2018asymmetric}. This privileged critic and the single successful
run make the experiment a proof of possibility, not evidence of robust or
sample-efficient learning.

On 24 held-out abstract streams, first-sight commitment falls from 75\% for the
base model to 32\% after training; lateness rises from 0.375 to 0.903; and
collected items increase from 87\% to 101\% of the Bayesian comparator.

\subsection{Lexical generalization}

A direct concern is that urn-only training may teach a surface rule over
\emph{balls}, \emph{colors}, and \emph{bags} rather than an allocation policy.
We therefore evaluate the unchanged checkpoint on three held-out vocabularies
never observed during training: coins distinguished by crest and placed in a
treasure chest, arrows distinguished by feather and placed in a quiver, and
potions distinguished by label and placed in a cauldron. Every content word is
replaced while the latent streams, horizon, budget, and free-text
\textsc{keep}/\textsc{pass} decision structure remain fixed.

The reserve behavior transfers cleanly. Pooled across the three reskins,
RL-final makes 19\% of commitments on first sight, compared with 89\% for the
base model, and has mean lateness 0.968 versus 0.134. The RL model's
per-vocabulary first-sight rates remain in a 10--33\% band, whereas the base
model ranges from 71--100\%. Thus the learned disposition is not a memorized
response to ball/urn vocabulary. This control establishes \emph{lexical}
generalization, not general task transfer: all three reskins retain the
abstract keep/pass structure on which the policy was trained.

\subsection{Decision modality and reusable-script transfer}

The final tool evaluation compares matched q8\_0 base and RL models on 24
paired A2 streams, with calibrated script correctness and robust empty-response
retries. Both channels are mechanically clean: there are no malformed, unknown,
or refused calls and no token-cap hits. Nevertheless, the trained policy makes
95\% of tool builds on first sight (58/61), identical in percentage to the base
control (59/62), despite its 32\% abstract result. To separate construction
from action modality, we also express the reskinned abstract task through
isomorphic zero-argument \textsc{keep}/\textsc{pass} tool calls. Transfer is
partial and vocabulary-sensitive: pooled first-sight commitment is 62\% for
RL-final versus 99\% for base, and RL-final ranges from 44\% to 97\% across
vocabularies. In the cauldron condition, RL-final keeps the first three distinct
potions and exhausts its budget by decision turn three in 16 of 24 seeds,
despite receiving byte-identical class sequences to the other reskins. Because
the transcripts contain no explanatory reasoning, we report the vocabulary
dependence without attributing a semantic cause.

The combined result is more specific than either ``vocabulary overfit'' or an
absolute tool-call wall. The learned policy generalizes across unseen lexical
surfaces, degrades under a modality change, and fails most strongly in
constructive script context (Figure~\ref{fig:rl-transfer}).

policy possession with constructive suppression, and cross-frame preservation.

Opus reserves completely in the urn but uses all of its script budget at first
sight. GPT-5.4-mini passes the preregistered abstract gate, then rises from
16.7\% R0 to 87.9\% R2c first-sight commitment; the paired difference is
$+75.8$ points with a 95\% bootstrap interval of $[+54.5,+93.9]$. Seed-level
heterogeneity remains: one R2c seed waits substantially and one makes no
commitments.

GPT-5.6 Sol also passes the abstract gate, collecting 98.5\% of the Bayesian
comparator's payoff. Unlike the affected models, it remains selective when code
is required: R0 and R2c first-sight rates are 19.4\% and 27.8\%, with mean
lateness 1.14 and 1.11. The paired difference is $+8.3$ points with a 95\%
interval of $[-11.1,+27.8]$. Under the locked protocol, Sol preserves the
timing policy across construction.

This result is positive evidence for the benchmark. Code generation does not
mechanically force eager commitment, and the task is not an impossible trap.
It can distinguish a model that integrates allocation with construction from
models that demonstrate allocation only abstractly. The two GPT points do not,
however, establish that scale or generic capability causes preservation.
Post-training, architecture, reasoning policy, and tool-use experience remain
possible explanations.

\section{Discussion}

\paragraph{Possession, acquisition, and activation.}
The experiments separate three questions that ordinary tool benchmarks
conflate. A policy may be absent, as in baseline Qwen; acquired from reward but
context-bound, as in the Qwen case study; or already present but suppressed by
constructive framing, as in Haiku, Opus, and GPT-5.4-mini. GPT-5.6 Sol shows
that activation during construction is itself a measurable capability.

\paragraph{Why might construction suppress allocation?}
Required code emission may invoke a reactive coding-assistant policy centered
on solving the visible instance. It may also collapse ``solve now'' and
``invest for later'' into one salient action. R2c rules out correctness stakes
and hand-solving availability as necessary causes, but it does not identify a
neural mechanism. The transcript and code-quality evidence supports
current-instance fixation only as a bounded behavioral interpretation.

\paragraph{Implications for agents.}
Tool-building systems should separate the decision to invest from execution of
the build. An explicit recurrence ledger, remaining-budget state, or evidence
threshold could make the investment decision legible before code generation
begins. These are design implications, not tested interventions. Evaluation
should score delayed utility and library opportunity cost rather than only
immediate task success or tool correctness.

\paragraph{Implications for capability evaluation.}
A useful online-investment evaluation needs two conditions. An abstract
competence gate establishes that the model can reserve at all; the constructive
condition tests whether timing survives realistic action. Either alone is
ambiguous. Future work should test whether cross-frame preservation predicts
the quality of libraries and long-horizon resource allocation in naturalistic
repository, data-cleaning, API, and analysis workloads.

\section{Limitations}

The benchmark uses one synthetic numeric environment with engineered hot and
trap recurrence. Real tasks have ambiguous class boundaries, nonstationary
frequencies, partial reuse, and variable construction quality. R2c intentionally
decouples payoff from correctness to isolate code emission; it is not a
realistic model of artifact value.

The core causal ladder is centered on Haiku and uses 12 independent canonical
streams. Hundreds of crossed sessions do not increase the independent stream
sample beyond 12. The model panel establishes heterogeneity and achievability,
not a scaling trend or broad population estimate. The full economic response
surface is run only on Haiku, so GPT-5.6 Sol's result demonstrates cross-frame
timing preservation, not economic optimality at varying prices.

The Bayesian urn comparator is prior-dependent and mismatched to the engineered
generator. We therefore treat timing as primary and use the exact hindsight
net optimum only for realized economic regret. That optimum is unavailable to
an online model and should not be mistaken for an implementable policy.

The RL evidence contains one successful run and a privileged critic. It does
not show robust retraining, non-privileged learnability, or sample efficiency.
Finally, prompt and tool-choice formats affect deliberation. The framing ladder
is coarse rather than fully factorial, and the R1-to-R2 contrast bundles action
labels with problem content. Harness repairs were logged transparently, but
occurred during benchmark development.

\section{Conclusion}

Reusable tool creation is not only a coding problem; it is an online investment
decision under uncertain reuse. Paired experiments show that several models
which reserve abstractly commit immediately when required to emit code. In
Haiku, required code emission reproduces the full shift and renders commitment
nearly invariant to visible economics. A learned Qwen reserve policy likewise
remains context-bound. Yet GPT-5.6 Sol preserves reserve across the locked
framing change, demonstrating that online allocation during constructive action
is difficult but achievable. Online tool investment is therefore a distinct
capability worth measuring, not a universal model failure.
